# Escalas salariales

## Crear o editar una escala
Desde Escalas Salariales > Escalas podés filtrar por Id o descripción, crear una escala o editar una existente. La escala tiene una descripción. Guardá la descripción antes de administrar sus categorías.

En el detalle de una escala, la tabla Categorías muestra número, descripción y monto. “Agregar categoría” permite crear una categoría; los números deben ser mayores que cero, la descripción es obligatoria y el monto no puede ser negativo. Usá los botones de edición o eliminación de la fila para mantener las categorías.

## Consultar las categorías de una escala
En el detalle de la escala se muestran sus categorías y montos. Desde el asistente también podés pedir las categorías indicando la descripción de la escala. Si hay varias escalas coincidentes, elegí la correcta antes de consultar sus categorías.

## Clonar una escala
Desde el listado de escalas, usá “Clonar” en la fila correspondiente. Indicá el nuevo período y un coeficiente de ajuste positivo. El sistema crea una escala con el período actualizado y ajusta los montos de sus categorías. Si ya existe una escala con el mismo nombre para ese período, el sistema permite elegir entre cancelar o actualizar la escala existente.

## Ver configuraciones asociadas
El botón “Configuraciones” de una escala permite consultar las configuraciones relacionadas. Para pasar configuraciones vigentes a una escala nueva en lote, usá Escalas Salariales > Actualización masiva.
