# Conceptos

## Buscar y revisar conceptos
En el menú Conceptos podés buscar por código, por código/subcódigo o por descripción. Para buscar ambos números usá el formato `25/100`; para buscar por descripción anteponé `d:`, por ejemplo `d:decreto`. También podés filtrar por tipo de concepto. La búsqueda se actualiza al escribir y la tabla permite cambiar de página.

La tabla muestra Id, código, subcódigo, descripción breve, descripción y tipo. El Id es el identificador interno; no es lo mismo que el código ni el subcódigo. El botón de detalle permite revisar las propiedades del concepto.

## Crear o editar un concepto
Usá “Nuevo concepto” o el botón de edición de una fila. Completá código, subcódigo, descripción breve, descripción y tipo de concepto, además de los demás campos disponibles, como meses aplicables, tipos de liquidación y propiedades. La descripción es obligatoria y tiene un máximo de 60 caracteres; la descripción breve admite hasta 10.

Al editar, revisá todos los campos antes de guardar. Si el sistema rechaza el cambio, el mensaje del formulario indica el problema que debe corregirse.

## Administrar fórmulas
Desde el botón de fórmulas de un concepto podés consultar, agregar o editar fórmulas. Cada fórmula tiene Condición y Acción. El editor permite buscar primitivas reconocidas e insertarlas en el campo que estés editando; también muestra tokens no reconocidos.

Usá “Verificar” antes de guardar para revisar la sintaxis y las primitivas. Guardar una fórmula vuelve a compilar el procedimiento asociado. Si aparecen errores, corregí las expresiones indicadas y verificá nuevamente.

## Ver configuraciones asociadas
El botón “Configuraciones asociadas” abre las configuraciones que contienen ese concepto. Si necesitás asociar o desasociar conceptos en lote, usá Asociación masiva > Conceptos.
