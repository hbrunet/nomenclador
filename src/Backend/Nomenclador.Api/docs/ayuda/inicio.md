# Inicio y navegación

## Iniciar sesión y recorrer la aplicación
Ingresá con el usuario y la contraseña habilitados para el sistema. Al iniciar sesión se abre Configuraciones. El menú superior permite ir a Configuraciones, Conceptos, Escalas Salariales, Valores fijos, Valores por categoría, Asociación masiva, Clonación masiva y Asistente. Las opciones de grupos están dentro de los menús de cada tipo de valor.

Si una pantalla muestra un error, leé el mensaje completo antes de volver a guardar. Los mensajes de validación indican qué dato hay que corregir; los avisos de confirmación permiten cancelar antes de una operación irreversible.

## Estados y períodos de vigencia
Las configuraciones pueden figurar como Activa, Futura o Vencida según el período activo del sistema y su rango de fechas. Las fechas se seleccionan por mes y año, y una fecha fin vacía representa una configuración sin fin de vigencia. No se permiten rangos superpuestos para la misma combinación de nomenclador, escala salarial y zona.

En las pantallas de filtros, “Vigente en” limita los resultados al período seleccionado. Si no aparecen registros, verificá el mes/año, el estado y los demás filtros antes de concluir que el registro no existe.

## Usar el asistente
Podés preguntarle en lenguaje natural por los datos del sistema o por cómo usar una pantalla. Para las preguntas de uso, el asistente busca información en este manual y responde con las instrucciones encontradas. Si no sabe qué pantalla o tarea querés resolver, puede pedirte que la aclares.

El asistente es de sólo consulta: no crea, modifica, elimina, clona ni asocia registros. Para esas operaciones, usá las pantallas correspondientes y revisá la confirmación antes de aceptar.
