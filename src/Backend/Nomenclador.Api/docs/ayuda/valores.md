# Valores fijos y valores por categoría

## Administrar valores fijos
En Valores fijos > Valores y Tipos, la pestaña Valores permite filtrar por descripción o tipo y por Id de tipo. “Nuevo valor” abre el formulario para completar descripción, tipo y valor numérico (no negativo). La descripción es obligatoria y admite hasta 40 caracteres.

La tabla permite editar o eliminar un valor fijo, clonarlo y consultar las configuraciones asociadas. La pestaña Tipos permite crear, editar o eliminar tipos. Un tipo que está siendo usado por valores no se puede eliminar.

Al editar un valor fijo ya asociado, el sistema permite actualizar el valor para todas las configuraciones que lo usan o crear un valor distinto solo para la configuración abierta. Revisá el alcance que muestra el diálogo antes de guardar.

## Administrar valores por categoría
En Valores por categoría > Valores y Tipos, la pestaña Valores permite filtrar por descripción o tipo y por Id de tipo. “Nuevo valor” requiere una descripción y un tipo. Después de guardar el valor, abrilo para administrar sus ítems.

Cada ítem relaciona un número de categoría con un importe no negativo. Usá “Agregar ítem” para incorporar una categoría e importe; los botones de fila permiten editar o quitar ítems. La pestaña Tipos sirve para crear, editar o eliminar tipos; un tipo utilizado por valores no puede eliminarse.

## Crear y usar grupos
Los menús Grupos de valores fijos y Grupos de valores por categoría permiten guardar conjuntos de tipos para reutilizarlos como filtros en operaciones masivas. Creá un grupo con una descripción y seleccioná los tipos que lo integran. El grupo filtra los valores disponibles; no selecciona registros automáticamente.

Los valores fijos tienen un importe único. Los valores por categoría contienen ítems con importes separados por número de categoría. No confundas el Id del valor con el Id de su tipo.
